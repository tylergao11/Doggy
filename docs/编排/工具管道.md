## 一句话

**两阶段：先全部问「能不能跑」，再批量真跑；结果写回对话，主循环继续想。**

---

## Phase 1 预检

- 解析参数 / MCP 名  
- PreToolUse **hooks**  
- **权限** / YOLO / Plan 门禁  
- 特殊路径（plan 退出、结构化输出等）

| 结果 | 是否结束 Turn | 意图 |
|------|---------------|------|
| Hook deny | **否** | 让模型改策略 |
| Permission reject | **是** | 安全不可协商 |
| 用户插话 | 否（换输入） | 新需求优先 |
| Cancel | 是 | 用户说停就停 |

---

## Phase 2 执行

| 规则 | 原因 |
|------|------|
| 同一文件编辑 → 串行 | 防互相覆盖 |
| 不同文件 / 无 path → 并行 | 快 |
| 目录 list 不按文件锁 | 避免误伤并发 |
