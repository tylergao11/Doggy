## 自检清单（写自己的 harness）

### 核心循环
- [ ] 有明确 Session / Turn 边界吗？  
- [ ] 「想→做→想」的退出条件列全了吗？  
- [ ] 用户中途插话会怎样？

### 工具
- [ ] 预检与执行是否分开？  
- [ ] deny 是否把原因返回模型？  
- [ ] 同文件写冲突如何处理？

### 多代理
- [ ] 子任务是否独立上下文？  
- [ ] 如何取消、如何等结果？

### 扩展
- [ ] Prompt / Hook / Tool 是否分通道？  
- [ ] 关键模式是否有硬约束（不只靠 prompt）？
