## 各层在干什么

| 层 | 一句话 | 关键组件 |
|----|--------|----------|
| ① 入口 | 人怎么连上 Agent | TUI / ACP / headless |
| ② Runtime | **真正编排** | SessionActor、队列、子代理协调 |
| ③ Agent | 配置包，不是循环 | prompt、tools、skills |
| ④ Tools | 能力列表 | 内置 + MCP，统一协议 |
| ⑤ Host | 碰真实世界 | 文件、Git、Shell、沙箱 |

![坐标系](images/00-坐标系.svg)

---

## 依赖方向（好记）

```text
pager(UI) → shell(编排) → agent(配置)
                 ↘ tools → workspace(主机)
                 ↘ mcp
```

**上层依赖下层，下层不知道界面。** 所以可以同一套 Runtime 服务 IDE 和 CI。
