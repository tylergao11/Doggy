## 一句话

**子代理 = 完整子 Session，不是函数调用；独立上下文，结束时摘要回传 parent。**

---

## 关键点

| 点 | 说明 |
|----|------|
| 默认后台 | parent 不被堵死 |
| 独立 context | 不共享全文，省主会话 token |
| 能力模式 | 只读 / 可写 / 可执行… |
| 隔离 | 可选 worktree 改代码不污染主目录 |

---

## Agent vs Persona

| | Agent | Persona |
|--|-------|---------|
| 配什么 | 模型、工具、prompt | 语气、焦点、I/O 契约 |
| 谁用 | 主会话或子会话 | **主要**叠在 subagent 上 |
| 例子 | `explore` / `plan` | `researcher` / `concise` |
