## 一句话

**一次用户输入 = 一个 Turn；Turn 里可以多次「模型想 → 工具做」。**

---

## 流程（对照看图）

| 步骤 | 发生什么 |
|------|----------|
| 入队 | Prompt 可排队；紧急可打断当前 turn |
| ① sample | 模型看历史 + 工具列表，决定说什么 / 调什么 |
| ② 分支 | 有 tool → 执行并写回结果 → 回到 ① |
| ③ 结束 | 没 tool 了（或被取消 / 达上限）→ 回复用户 |

---

## Turn 出口

| 出口 | 含义 |
|------|------|
| 正常完成 | 模型停手 |
| max_turns | 防无限工具环 |
| 权限拒绝 | 安全边界，整 turn 停 |
| 用户取消 | 立刻停 |
| 插话 / followup | **不结束**，塞进新消息再想 |

---

## 和普通聊天差在哪

| 普通 Chat | 这里 |
|-----------|------|
| 一问一答 | 多轮 tool 环 |
| 几乎无出口 | 取消 / 权限 / 插话都是一等公民 |
| 无模式 | Normal / Plan / Goal… |
