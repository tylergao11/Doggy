# Plan mode removed

Plan mode has been **removed** from Doggy.

Use:

| Posture | How | Meaning |
|---------|-----|---------|
| **Auto** | Default / Shift+Tab | Ordinary chat with full tool permission |
| **Goal** | Shift+Tab or `/goal <objective>` | Automatic run until **acceptance criteria** pass independent audit |

Goal is acceptance-criteria driven: completion means every gating criterion holds.
Independent audit (他测) judges criteria one by one; implementer self-tests are not the pass gate.
